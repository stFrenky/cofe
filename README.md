# Houston Coffee — landing

Премиальный одностраничный лендинг кофейни **Houston Coffee** («Хьюстон, у нас кофе.»).

- `index.html` — готовый самодостаточный файл: все изображения, логотип и three.js инлайнены. Открывается с диска, без сборки и сервера. Единственная внешняя зависимость — Google Fonts (Prata + Manrope), при отсутствии сети подставляются системные шрифты.
- `src/template.html` — исходник с плейсхолдерами `__ASSET_<name>__` и `__THREE__`.
- `src/assets/` — вырезанные из брендбука маски логотипа (PNG с альфой), продуктовые кадры, `three.js` (r160, UMD), исходный брендбук `brand-source.jpg`.
- `build.py` — собирает `index.html` из шаблона и ассетов: `python3 build.py`.

## Структура страницы
1. Hero — sticky-сцена на three.js, скролл управляет четырьмя фазами: стакан Ivory → входит Terracotta → меняются местами → финал. Мышь даёт лёгкий параллакс.
2. Бегущая строка — направление и скорость следуют за скроллом.
3. О нас — фото айдентики с clip-reveal и параллаксом, принципы.
4. Айдентика — рельс карточек (носители бренда) и палитра Ivory / Espresso / Terracotta.
5. Меню — 4 позиции.
6. Атмосфера — тёмный блок, вращающийся стикер, цитата.
7. Контакты, футер.

## Что заменить перед запуском
Адрес, телефон, соцсети, часы работы и цены в меню — плейсхолдеры в `src/template.html` (секции `#menu` и `#visit`), затем `python3 build.py`.
